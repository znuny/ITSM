ITSM Bundle
===========

**Feature List**

This package is the ITSM bundle for Znuny. Installing it deploys the complete Znuny ITSM stack. The following packages are included:

- **ITSMCore**: Core ITSM functionality and base framework
- **GeneralCatalog**: General catalog for ITSM item definitions
- **ImportExport**: Import/export framework for ITSM data
- **ITSMChangeManagement**: Change and work order management, CAB, templates
- **ITSMConfigurationManagement**: Configuration items (CIs) and relationships
- **ITSMIncidentProblemManagement**: Incident and problem management
- **ITSMServiceLevelManagement**: Service level agreements (SLAs) and management

**Prerequisites**

- Znuny 7.3 (or compatible version per bundle release)

**Installation**

If you upload the package via the GUI, you may need to adjust the following configuration beforehand: `WebMaxFileUpload` to `30000000`.

Download the [package](https://download.znuny.org/releases/itsm/bundle7/) and install it via admin interface -> package manager.
